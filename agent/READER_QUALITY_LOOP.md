# 공통 독자 품질 자동 복구 계약

이 계약은 2026-09-02 이후 생성하는 월요일부터 토요일까지의 모든 정규 글에
적용한다. `8.5`는 낮은 초안을 사용자에게 넘기기 위한 실패 점수가 아니라,
Codex가 같은 실행 안에서 원고를 고치는 자동 재편집 신호다.
원고를 쓰기 전에 `agent/WEEKLY_READER_PROMISES.md`를 읽는다. 레이아웃·이미지·
출처·광고·모바일 호흡은 공통으로 유지하되, 독자 수준과 전개는 요일별 약속을
따른다.

## 종료 불변 조건

- `reader_scores.general_reader_understanding >= 8.5`
- `reader_scores.public_readability >= 8.5`
- `editorial.reader_path`가 요일별 독자·본문 순서와 일치
- 최종 `daily_guard` 또는 `saturday_guard`가 `COMPLETE`

네 조건을 모두 만족하기 전에는 발행 도우미를 완성본으로 보고하거나 커밋하지
않는다. `quality_reader_path`나 `quality_reader_access`가 남은 상태를 `PARTIAL`,
`BLOCKED`, 재실행 요청으로 사용자에게 넘기지 않는다. 티스토리 직접 발행은 하지 않는다.

## 같은 실행에서 수행할 복구 루프

1. 요일별 독자 약속에 맞춰 `editorial.reader_path`의 `reader_level`,
   `entry_heading`, `immediate_answer`, `action_steps`, `completion_check`를 먼저
   설계한다. 화·목은 `advanced_heading`도 정하고, 심화 전까지 일반 독자가 답과
   확인 방법을 끝낼 수 있게 한다.
2. 원고 JSON에 `reader_access.quick_summary` 세 문장과
   `reader_access.glossary` 3~5개를 작성한다. 요약은 문제·선택·한계를 한 문장씩
   답하고, 용어 풀이는 본문 초반의 낯선 말부터 쉬운 한국어로 설명한다. 이 값은
   최종 HTML의 `30초 요약`과 `먼저 알아둘 말`로 실제 표시된다.
3. 원고 JSON을 만든 직후 해당 초안의 `daily_guard --source-only`를 실행하고
   출력의 `reader_scores`와 `reasons`를 읽는다.
4. `quality_reader_path`가 나오면 즉답, 앞부분의 실제 목록, 심화 시작점, 마지막
   확인 문장을 먼저 고친다. 필드값만 본문에 맞춘 척하지 않고 독자의 읽는 순서를
   다시 설계한다.
5. 이해도가 낮으면 도입 첫 5문장을 `독자가 마주친 장면 → 먼저 답할 결론 →
   끝까지 읽고 얻을 판단` 순서로 다시 쓴다. 약어와 내부 구현명은 쉬운 말 뒤에
   한 번만 설명하고, 구체적인 예시 하나를 앞부분에 둔다.
6. 가독성이 낮으면 긴 문단을 한 생각씩 나누고, 소제목·목록·설명 이미지를
   사용해 같은 종류의 본문 블록이 4개 넘게 이어지지 않게 한다. 표는 4열 이하,
   긴 코드는 접기 또는 핵심 부분만 남긴다.
7. JSON을 저장하고 `daily_guard --source-only`를 다시 실행한다. 독자 경로를
   통과하고 두 점수가 모두 8.5 이상이 될 때까지 4~7단계를 반복한다.
8. 같은 원인이 두 검사에서 연속으로 남으면 문장을 조금씩 덧대지 않는다. 해당
   도입·문단·표·코드 블록을 삭제하고 일반 독자의 질문 순서로 새로 쓴다.
9. 점수는 통과했지만 설명을 성립시키는 근거가 부족하면 이전 후보를 억지로
   사용하지 않는다. 공식 자료와 독립 자료를 다시 조사해 같은 질문을 보강하고,
   그래도 주제가 성립하지 않으면 검증 가능한 다음 후보로 원고를 새로 만든 뒤
   이 루프를 처음부터 적용한다.
10. 두 점수가 통과한 원고만 이미지·HTML·발행 도우미를 생성한다. 최종 내보내기
   뒤 메타 JSON의 `reader_scores`가 같은 값인지 확인하고 완성 가드를 실행한다.

자동 점수만 보고 끝내지 않는다. 마지막에는 해당 요일의 처음 온 독자를 가정해
제목과 첫 부분만으로 핵심 답을 설명할 수 있는지, 한 가지 행동·선택을 끝낼 수
있는지, 어려운 세부를 건너뛰어도 글의 약속이 지켜지는지 직접 읽어 본다.

이 루프는 트래픽을 보장하는 수치가 아니다. 검색 유입을 얻을 기회를 해치지
않도록 제목의 검색 질문, 공식·독립 근거, 실제 예시, 쉬운 모바일 읽기 흐름을
동시에 만족시키는 최소 발행 기준이다.
