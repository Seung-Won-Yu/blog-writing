# AdSense 사이트 재검토 계약

목표는 승인 숫자를 맞추는 것이 아니라, 공개된 모든 페이지에서 독자가 얻는 고유한 가치를 분명하게 만드는 것입니다. Google은 최소 글자 수·최소 게시물 수를 공개하지 않았습니다. 이 저장소의 길이·구조 점수는 정리 우선순위를 위한 내부 휴리스틱일 뿐 승인 기준이 아닙니다.

## 2026-08-24 현재 기준선

- 사이트: `https://won0322.tistory.com`
- 사용자가 알린 상태: AdSense 검토 탈락
- 이전 확인 사유: `가치가 별로 없는 콘텐츠`
- 연결 상태: Tistory 연결 완료
- `ads.txt`: 해당 사항 없음
- 공개 글 감사: 93개 중 `high` 0개, `review` 0개, 오류 0개
- 내부 링크: 삭제·비공개 글을 가리키는 링크 0개
- 광고 슬롯: 페이지당 최대 5개, 4개 이상인 글 93개

콘텐츠 감사 결과는 이전보다 분명히 개선됐지만 AdSense 승인을 보장하는 점수가 아닙니다. 현재 계정의 정확한 사유와 재검토 가능 상태는 AdSense `사이트`·`정책 센터` 화면을 최종 기준으로 확인합니다.

Google은 신청 URL 하나가 아니라 사이트 전체를 검토할 수 있습니다. 최근 심층글만 좋아도 예전 공개 글에 중복 요약·문제 덤프·링크 모음이 많이 남아 있으면 사이트 수준 위험이 계속됩니다.

## 공식 기준을 이 블로그에 적용하는 법

1. **고유한 가치**
   - 원문 요약을 여러 개 이어 붙이지 않습니다.
   - 직접 실행한 결과, 비교, 실패 조건, 적용 범위, 운영자의 판단 중 하나 이상을 핵심 가치로 둡니다.
2. **사람 우선**
   - 검색 유입만 노린 넓은 주제보다 기존 독자가 실제로 해결할 질문 하나를 끝냅니다.
   - 제목만 바꾼 유사 글을 여러 개 만들지 않습니다.
3. **신뢰**
   - 공식 원문·문서와 독립 자료를 구분합니다.
   - 직접 실행하지 않은 결과를 체험처럼 쓰지 않습니다.
   - 운영 안내에서 누가, 왜, 어떻게 글을 만드는지 밝힙니다.
4. **완성도**
   - 제목, 본문, 출처, 이미지 설명, 관련 글, 모바일 레이아웃이 모두 완성된 페이지만 공개합니다.
   - 공사 중, 빈 목록, 깨진 링크, 삭제한 글로 향하는 관련 링크를 남기지 않습니다.
5. **명확한 탐색**
   - 카테고리는 `IT 트렌드 해설`, `실전 IT 아티클`, `개발·자격증 노트` 중심으로 유지합니다.
   - 운영 안내·개인정보 처리·연락 경로를 방문자가 찾을 수 있어야 합니다.
6. **광고 배치**
   - 광고가 메뉴·버튼과 붙거나 본문을 가리거나 화면 밖으로 밀어내면 안 됩니다.
   - 콘텐츠가 없는 목록·탐색 화면에 광고만 두드러지게 만들지 않습니다.
   - 게시자 콘텐츠보다 광고·유료 프로모션이 많아 보이지 않게 합니다.
7. **개인정보와 정확한 선언**
   - 개인정보처리방침에 쿠키, 웹 비콘, IP 주소, 제3자 광고 데이터 수집을 공개합니다.
   - Google 파트너 사이트 데이터 사용 안내 링크를 둡니다.
   - 게시자·작성자·사이트 목적·서비스 제휴 관계를 사실과 다르게 표현하지 않습니다.

## 공개 콘텐츠 감사

```bash
python3 -m blog_pipeline.collection.audit_tistory_content
```

결과의 `high`는 비공개·통합·중복 확인 우선순위입니다. 자동 삭제 명령이 아닙니다. `thin_text`, `generic_summary_title` 같은 단일 신호만으로 글을 없애지 않고 실제 고유 가치와 대체 글 존재 여부를 확인합니다.

의도적으로 공개 글을 한꺼번에 비공개·삭제한 직후에만 sitemap 기준선을 한 번 갱신합니다.

```bash
python3 -m blog_pipeline.collection.sync_tistory_posts --allow-shrink
```

평상시 수집 작업은 이 옵션을 쓰지 않습니다. 예상하지 못한 대량 누락은 계속 실패해야 합니다.

## 재검토 요청 전 최종 게이트

- 품질 감사의 `high` 글을 모두 직접 판정하고, 남기는 이유 또는 처리 결과를 기록했습니다.
- 통합본 공개 확인 뒤에만 흡수 원문을 비공개·삭제했습니다.
- sitemap에서 비공개·삭제 글이 빠지고 새 통합 URL이 나타납니다.
- 관련 글 링크가 존재하는 공개 URL만 가리킵니다.
- 홈·카테고리·운영 안내·개인정보 공지가 모바일과 데스크톱에서 열립니다.
- 자동 상단·하단·사이드바 광고를 정리하고 본문 광고가 문단·이미지·탐색을 방해하지 않습니다.
- 최근 글에 자동 생성 다이제스트, 다중 뉴스 짜깁기, 문제 덤프가 없습니다.
- 위 상태와 AdSense 화면의 현재 사유를 다시 확인한 뒤 재검토를 요청합니다.
