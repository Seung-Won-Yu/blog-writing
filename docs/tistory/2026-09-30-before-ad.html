GitHub Actions 러너에서 Node 20 제거, JavaScript 액션은 Node 24로 전환

GitHub는 Actions 러너에서 Node 20을 제거하고 JavaScript 액션을 Node 24로 실행한다. 임시 우회 변수는 더는 사용할 수 없고, 액션 제작자는 runs.using을 node24로 바꾸며 사용자는 Node 24 지원 액션 버전으로 올려야 한다.

먼저 애플리케이션 Node와 액션 런타임을 분리한다

이번 종료 대상은 JavaScript 액션을 실행하는 러너 내장 Node 20이다. 워크플로가 actions/setup-node로 설치해 테스트하는 Node 버전과는 별개다. node-version: 20이 보인다는 이유만으로 애플리케이션 테스트 환경부터 바꾸면 실제 액션 오류는 그대로 남을 수 있다.

워크플로 사용자는 uses: 버전을, 액션 제작자는 action.yml과 배포 번들을, 셀프 호스티드 운영자는 러너의 Node 24 내장 여부를 확인해야 한다. 먼저 실패 로그가 어느 액션을 실행하다 멈췄는지와 /externals/node24 같은 경로를 가리키는지 확인한다.

  • 워크플로의 uses: 줄을 모아 오래된 액션 메이저 버전이 있는지 확인한다.
  • 직접 만든 액션이면 action.yml의 runs.using과 배포된 JavaScript 번들을 함께 확인한다.
  • 셀프 호스티드 러너면 러너 버전·운영체제·아키텍처와 externals/node24 존재를 확인한다.
  • 작은 검증 워크플로에서 먼저 통과시킨 뒤 원래 작업으로 변경 범위를 넓힌다.

같은 워크플로 안에도 Node 버전은 두 층이 있다

uses: vendor/action@v1 같은 JavaScript 액션은 액션 저장소의 action.yml에 적힌 runs.using을 따른다. 반면 run: npm test는 워크플로가 준비한 Node에서 실행된다. 둘은 같은 작업 로그에 이어 나오지만 버전을 결정하는 파일과 책임자가 다르다.
