Codex Security 0.10.0, 중단된 Standard 검사 재개 지원

2026년 11월 12일 공개된 0.10.0은 저장된 Standard 검사를 원래 세션에서 이어갈 수 있게 했다. 저장된 ID와 설정, 누적 사용량은 기존 검사에 이어진다.

검사 ID로 저장된 상태부터 확인한다

연결이 끊기면 저장된 검사 ID의 상태를 확인한다. 실행 중인 작업이 없고 복구 가능한 running 기록이 남으면 재개한다.

  • 검사를 시작한 환경에서 저장된 검사 ID로 상태와 세션 로그를 확인한다.
  • 다른 작업자가 같은 검사를 실행 중인지 확인한다.
  • 복구 명령이 표시되고 원래 작업 폴더와 상태가 남아 있으면 같은 ID로 재개한다.
  • 실패나 취소로 닫힌 검사는 원인을 확인하고 새 검사로 다룬다.

0.10.0에서 달라진 것은 검사 중단 이후다

11월 12일 공개된 0.10.0은 기존 재개 명령의 대상을 Standard 검사까지 넓혔다. 연결 장애가 발생하기 전에 세션이 저장됐다면 원래 Codex 세션을 이어 쓴다. 검사 ID, 저장된 설정, 누적 사용량과 기존 예산이 이어지고, 체크포인트 뒤 저장되지 않은 작업은 다시 수행할 수 있다.

예를 들어 사내 검사 화면이 결과를 기다리다 시간 초과됐다고 하자. 앱에서 응답이 끊겨도 바로 재시도 큐에 넣지 않고 검사 ID로 원래 실행을 확인하면, 아직 살아 있는 검사와 복구할 검사를 구분할 수 있다. 코드나 검사 범위를 바꾼 결과가 필요하다면 새 검사로 남겨야 두 보고서가 어느 코드를 다루는지 구분할 수 있다.
