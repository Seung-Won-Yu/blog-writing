가족과 함께 쓰는 컴퓨터에서 선물을 검색할 때 시크릿 모드를 켜곤 한다. 검은 창을 닫으면 흔적이 모두 사라진다고 생각하기 쉽다. 실제로 방문 기록과 쿠키는 세션이 끝난 뒤 기기에 남지 않는다. 하지만 다운로드한 파일과 북마크는 남고, 웹사이트와 네트워크의 관찰까지 멈추는 것은 아니다. 그렇다면 시크릿 모드는 누구에게서 무엇을 숨겨 주는 기능일까?

  • 공유 기기의 다음 사용자에게 흔적을 덜 남길 때 유용하지만, 다운로드·북마크와 온라인 접속 기록은 별도다.
  • 웹사이트·로그인 계정·회사나 학교 네트워크에서 익명으로 보이게 하는 기능은 아니다.

먼저 알아둘 말

시크릿 모드
평소 창과 분리된 임시 브라우징 세션을 만들고, 모든 비공개 창을 닫을 때 그 세션의 로컬 기록을 정리하는 기능이다.
쿠키
웹사이트가 로그인 상태나 장바구니처럼 방문 사이에 이어 쓸 작은 값을 브라우저에 저장하는 방식이다.
브라우저 지문
화면 크기·브라우저 설정처럼 여러 특징을 조합해 같은 브라우저인지 추정하는 추적 단서다.

원리를 쉽게 풀어보면

비공개 브라우징은 세션 종료 뒤 기기의 방문 기록과 임시 사이트 데이터를 정리하지만 다운로드·북마크와 외부 관찰 기록까지 지우지는 않는다.

시크릿 모드는 기록 삭제 기능이지 투명 망토가 아니다

시크릿 모드는 모든 비공개 창을 닫은 뒤 방문 기록·쿠키·사이트 데이터를 기기에 남기지 않지만, 파일·북마크와 웹사이트·네트워크 쪽 기록까지 없애지는 않는다. ‘아무 기록도 남지 않는다’는 믿음은 절반만 맞다. 주요 브라우저의 비공개 창은 같은 기기의 다음 사용자에게 방문 흔적을 덜 남기는 데 초점이 있다.

1분이면 남는 것과 지워지는 것을 가를 수 있다

내 기기에서 남는 흔적을 확인하려면 컴퓨터용 Chrome의 두 화면, 방문 기록과 북마크 관리자를 비교하면 된다. 민감한 검색어·로그인·다운로드 없이 example.com으로 확인한다. 아래는 공식 도움말에 따른 절차와 예상 결과이며 이번 보완에서 Chrome 실험을 수행한 기록은 아니다.

  • 컴퓨터용 Chrome의 더보기(⋮) → 새 시크릿 창을 연다. Windows는 Ctrl+Shift+N, Mac은 ⌘+Shift+N도 된다.
  • 시크릿 창에서 https://example.com/?private-check=0903 주소를 연다. 재확인할 때는 0903을 자신만의 새 숫자로 바꾼다.
  • 주소창 오른쪽 별표로 북마크를 추가하고 이름을 ‘비공개 확인 0903’으로 저장한다. 숫자를 바꿨다면 이름도 맞춘다.
  • 열려 있는 시크릿 창을 모두 닫고 같은 Chrome 프로필의 일반 창을 연다.
  • 더보기 → 방문 기록 → 방문 기록에서 private-check를 검색한다. 더보기 → 북마크 및 목록 → 북마크 관리자에서는 저장한 이름을 검색한다.

예상 결과는 방문 기록 검색에서 고유 주소가 나오지 않고 북마크 관리자에는 저장한 이름이 보이는 것이다. 북마크를 열어 주소를 확인하면 일반 창에 새 방문 기록이 생기므로 먼저 검색 결과만 비교한다. 실험 뒤에는 자신이 만든 테스트 북마크만 정리한다.

주소창에 example.com이 추천돼도 이번 시크릿 방문이 저장됐다고 단정하지 않는다. 기존 일반 창의 방문 기록이나 남겨 둔 북마크가 추천될 수 있다. 이번에 쓴 고유 숫자와 방문 시각을 방문 기록 화면에서 비교해야 한다.

  • 고유 주소가 방문 기록에 보이면 일반 창에서 먼저 열었거나, 북마크를 눌러 다시 방문했는지 확인한다. 다른 숫자로 다시 비교하고 기존 기록을 지워 결과를 맞추지 않는다.
  • 북마크가 안 보이면 저장 완료와 같은 Chrome 프로필인지 확인한다. 메뉴를 찾기 어렵다면 참고 자료의 Chrome 북마크 도움말을 연다.
  • 휴대폰이나 Firefox·Safari에서는 메뉴와 세션 관리가 다르다. 컴퓨터 경로를 그대로 적용하지 말고 해당 브라우저의 공식 도움말을 따른다.

다운로드 기록 목록과 파일 자체도 별개다. 시크릿 창을 닫아 다운로드 목록에서 항목이 사라져도 저장한 파일은 다운로드 폴더 등 지정한 위치에 남을 수 있다. 파일이 걱정되는 상황이면 브라우저 기록 화면보다 파일 관리자에서 저장 위치를 확인한다.
