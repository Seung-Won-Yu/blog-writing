구조화 출력은 어디까지 믿을까: JSON 스키마와 Pydantic 검증 선택 기준

문법·계약·원문 일치를 나눠 구조화 출력과 검증 도구의 쓰임·생략 조건을 고른다.

잘 열린 JSON과 맞는 데이터는 다른 통과선이다

JSON 스키마는 출력의 모양과 표현 가능한 제약을 정한다. 제약 디코딩은 생성 중 허용된 토큰을 고르고, Pydantic은 받은 값을 검사한다. 어느 쪽도 원문에 없는 사실을 자동으로 찾아내지는 않는다.

  • 깨지는 결과가 JSON 문법인지, 필드·타입인지, 원문과 다른 값인지 먼저 나눈다.
  • 문법·모양 문제는 제공자의 구조화 출력이나 Outlines의 지원 범위를 확인한다.
  • 필드 간 관계와 타입 변환 정책은 Pydantic 검증으로 명시한다.
  • 원문 대조에 실패하거나 정보가 없으면 저장을 보류할 경로를 정한다.

가상의 행사 안내 추출 앱을 생각해 보자. 원문에는 날짜가 없는데 결과에 날짜 문자열이 들어 있다. 필드가 있고 날짜 형식도 맞으면 모양 검사에는 통과할 수 있다. 하지만 그 날짜의 근거가 생긴 것은 아니다. 이 사례는 직접 실행한 결과가 아니라 검사의 경계를 설명하는 예시다.

먼저 성공을 세 갈래로 나눈다. 파일을 읽을 수 있는가, 앱이 정한 계약에 맞는가, 입력 근거와 일치하는가다. 뒤 단계의 질문을 앞 단계 도구에 맡기면 “검증 성공”이라는 같은 문구를 보고도 서로 다른 상태를 떠올리게 된다.

Outlines는 완성된 문자열을 고치는 도구일까

Hugging Face의 TGI Guidance 문서는 생성 요청에 문법을 넣고, 다음 토큰을 고르기 전에 허용되지 않은 후보를 가리는 과정을 설명한다. 완성된 JSON에서 쉼표를 고치는 후처리와 다르다. 생성 중 선택지를 제한하는 방식을 제약 디코딩이라고 부른다.

Outlines 공개 README는 Python 타입과 Pydantic 모델 등으로 원하는 출력 형식을 전달하는 예를 보여 준다. 이때 모델은 “이 모양으로 부탁해”라는 문장만 받는 것이 아니다. 지원되는 실행 경로에서는 형식에 맞는 출력 공간이 생성 과정에 반영된다.

따라서 닫히지 않은 괄호나 정해진 선택지 밖의 분류명이 반복 문제라면 생성 쪽 제약을 먼저 볼 이유가 있다. 반면 이미 파싱은 되는데 회사명이나 날짜가 틀린다면, 형식 도구를 바꾸기 전에 원문 대조와 실패 사례를 확인해야 한다.

Outlines가 Python 타입을 받는다는 설명을 “내 Python 검증 함수도 생성 중 그대로 실행된다”로 읽으면 곤란하다. 생성기에 전달되는 스키마와 앱에서 실행되는 사용자 검증 코드는 다른 대상이다. 지원 백엔드·타입·스키마 제약의 범위를 각각 확인해야 한다.

어디에서 깨졌는지에 따라 먼저 볼 곳
보이는 실패먼저 볼 수단남는 확인
괄호·따옴표가 깨짐구조화 출력·제약 생성중단·잘린 응답 처리
필수 필드·선택지 위반지원 스키마 제약미지원 제약 확인
종료일이 시작일보다 빠름앱의 관계 검증규칙이 실제 실행되는지
형식은 맞는데 원문과 다름근거 대조·보류 경로정보 부족을 인정하는지

문법만 맞게 만드는 JSON 모드와 특정 스키마를 따르게 하는 기능도 구분한다. 제품마다 이름과 지원 범위가 다르므로 기능 이름 하나만 비교하지 않는다. 실제 사용하려는 필수 필드·선택지·중첩 구조를 지원하는지가 먼저다.

Pydantic을 붙였는데 왜 틀린 값이 통과할까

Pydantic의 Validators 문서는 필드 하나와 모델 전체에 검증을 추가하는 방법을 구분한다. 날짜 두 개의 앞뒤 관계처럼 여러 값이 함께 있어야 판단하는 조건은 모델 수준에서 생각할 수 있다. 앱의 규칙을 코드로 명시할 때 쓰는 층이다.

모델 정의에서 날짜 필드 두 개를 만들었다고 날짜의 순서까지 검사되는 것은 아니다. “시작일 ≤ 종료일”이 계약이라면 그 규칙을 따로 표현해야 한다. JSON 스키마를 내보내 생성기에 전달하는 것과 Python 검증 함수를 실행하는 것도 구분한다.

Strict Mode 문서에는 문자열 숫자를 정수로 바꾸는 기본 동작과 엄격 모드에서 거절하는 예가 있다. 타입이 맞다는 뜻에는 “입력부터 맞았다”와 “허용된 변환 뒤 맞아졌다”가 섞일 수 있다. 변환을 허용할지는 데이터 계약에 맞춰 정해야 한다.
