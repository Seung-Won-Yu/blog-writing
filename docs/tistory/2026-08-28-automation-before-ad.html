견적서, 회의록, 영수증을 한 번에 보낼 때마다 파일 세 개를 열고 순서를 확인한다면 이 자동화를 그대로 따라 해볼 수 있다. PDF 이름 앞에 01, 02, 03을 붙여 폴더에 넣고 스크립트를 한 번 실행하면 순서대로 합쳐진 파일이 만들어진다. 왼쪽 목록에서 각 문서의 첫 쪽으로 바로 이동하는 책갈피도 함께 생기며, 이름만 PDF인 잘못된 파일은 결과에서 빠진다.

PDF 여러 개를 순서대로 합치고 책갈피까지 만드는 방법

Python 자동화가 처음인 사람도 준비물부터 실행 결과 확인까지 따라 할 수 있게 PDF 병합 과정을 단계별로 정리했다.

먼저 결과부터: 세 파일이 한 번에 열렸다

견적서, 회의록, 영수증을 메일 한 통에 붙일 때 파일을 세 번 열게 된다. 순서까지 중요하면 01, 02, 03으로 이름을 바꾸고 제대로 놓였는지 다시 확인해야 한다. 이번 방법은 이 세 파일을 한 번에 합치고, 잘못된 파일은 결과에서 빼준다.

완성된 PDF의 왼쪽 목록에는 견적서·회의록·영수증이라는 이동 메뉴도 생긴다. 여기서 책갈피란 긴 PDF를 계속 넘기지 않고 원하는 문서의 첫 쪽으로 바로 이동하는 메뉴를 뜻한다.

준비물은 Python과 복사본 폴더 하나

  • Python 3.9 이상이 설치된 Windows 또는 macOS 컴퓨터
  • 원본이 아닌 PDF 복사본 세 개 이상
  • 메모장이나 텍스트 편집기
  • 새로 만든 pdf-merge 작업 폴더

처음 한 번만 PDF 처리 도구인 pypdf를 설치한다. Windows는 첫 줄, macOS는 둘째 줄 중 자신의 운영체제에 맞는 한 줄만 실행하면 된다. Python이 설치되어 있지 않다면 먼저 Python 공식 설치 프로그램이 필요한 방식이다.

# Windows
py -m pip install pypdf==6.16.2

# macOS
python3 -m pip install pypdf==6.16.2

1단계: 합칠 순서대로 파일명을 정한다

pdf-merge 폴더 안에 input-pdfs 폴더를 만들고 PDF 복사본을 넣는다. 프로그램은 파일명 순서대로 합치므로 앞에 01, 02, 03을 붙인다. 파일명에서 확장자를 뺀 부분은 책갈피 이름으로도 사용된다.

pdf-merge/
├─ merge_pdfs.py
└─ input-pdfs/
   ├─ 01-견적서.pdf
   ├─ 02-회의록.pdf
   └─ 03-영수증.pdf

파일명합쳐지는 위치생성되는 책갈피
