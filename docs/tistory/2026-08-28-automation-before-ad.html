PDF 합치기 가장 쉬운 방법: Mac·Windows·반복 자동화

한두 번 합칠 때는 코딩 없는 방법으로 끝내고, 같은 작업이 매달 반복될 때만 입력 검사와 책갈피가 있는 자동화로 확장한다.

어떤 방법이 가장 쉬울까?

견적서·회의록·영수증을 한 파일로 보내려는 순간, 검색 결과가 Python 코드부터 보여 주면 해결보다 준비가 더 커진다. 한두 번 합치는 일이라면 프로그램을 만들 이유가 없다. Mac은 기본 미리보기 앱으로 끝낼 수 있고, Windows는 PDF24 Creator처럼 파일을 컴퓨터 안에서 처리하는 화면 도구가 더 쉽다.

자동화가 필요한 경우는 따로 있다. 매달 같은 형식의 문서를 같은 순서로 묶고, 이름만 PDF인 잘못된 파일을 걸러내며, 긴 결과에 문서별 책갈피까지 넣어야 할 때다. 아래 표에서 자신의 상황 한 줄만 고르면 된다. 처음부터 모든 방법을 따라 할 필요는 없다.

회사 문서나 개인정보가 든 파일이라면 편하다는 이유만으로 웹 변환 사이트에 바로 올리지 않는 편이 안전하다. 서비스마다 업로드·보관·삭제 정책이 다르기 때문이다. 이 글은 Mac 기본 기능과 Windows 오프라인 도구를 먼저 두고, 반복 작업용 코드도 로컬에서만 실행한다.

Mac: 미리보기 앱으로 합친다

Mac에는 별도 설치가 필요 없다. Apple은 미리보기에서 여러 PDF의 전체 내용이나 선택한 페이지만 다른 PDF로 옮길 수 있다고 안내한다. 다만 미리보기의 변경사항은 자동 저장될 수 있으므로 원본을 남기려면 먼저 파일 > 복제를 선택해 사본에서 작업하는 것이 중요하다.

  • 합칠 PDF를 미리보기로 각각 연다.
  • 각 창에서 보기 > 썸네일을 눌러 왼쪽에 페이지 목록을 띄운다.
  • 한 PDF의 썸네일을 다른 PDF의 원하는 위치로 끌어놓는다.
  • 순서가 다르면 썸네일을 다시 끌어 옮긴 뒤 복사본을 저장한다.

파일 전체를 넣고 싶다면 Finder의 PDF 아이콘을 열려 있는 문서의 썸네일 사이드바로 끌어도 된다. 특정 페이지만 옮길 때는 Command 키를 누른 채 여러 썸네일을 고른다. 완성 파일을 닫기 전 첫 페이지와 마지막 페이지, 문서가 바뀌는 경계만 확인하면 한 번짜리 작업은 여기서 끝이다.

Windows: PDF24에 파일을 끌어놓는다

Windows 10·11에서는 PDF24 Creator를 한 번 설치해 두면 마우스로 합칠 수 있다. 공식 안내상 이 데스크톱 프로그램은 오프라인으로 작동하고 파일을 인터넷에 업로드하지 않는다. 개인용과 업무용 모두 무료이며, PDF 병합·분할·페이지 정렬을 드래그 앤 드롭 화면에서 처리한다.

  • PDF24 Creator를 공식 사이트나 Microsoft Store에서 설치해 연다.
  • 합칠 PDF를 화면으로 끌어놓고 원하는 순서로 다시 정렬한다.
  • 병합 기능을 실행한 뒤 결과를 새 이름으로 저장한다.
  • 완성 PDF를 열어 문서 경계와 전체 페이지 수를 확인한다.

PDF24는 Mac용이 아니므로 Mac 사용자는 앞의 미리보기가 더 간단하다. 회사가 승인한 프로그램만 설치할 수 있는 환경이라면 먼저 사내 정책을 확인한다. 설치 권한이 없다고 해서 민감한 문서를 임의의 온라인 사이트에 올리는 것으로 우회하지 않는다.
