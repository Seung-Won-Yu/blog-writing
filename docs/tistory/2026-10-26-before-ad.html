날짜 입력창에서 10월 26일을 골랐는데 저장된 값은 25일이다. JavaScript 날짜 하루 전 오류는 날짜만 필요한 값에 시각과 시간대 변환을 끼워 넣었을 때 생길 수 있다. 생일·마감일이라면 연월일을 그대로 보존하고, 특정 순간이라면 시간대가 드러나는 시각으로 다뤄야 한다. 먼저 입력·변환·저장·표시 중 어디서 값이 달라지는지 찾자.

날짜 전용 값과 순간을 구분하는 JavaScript 저장·표시 진단

Date 파싱과 UTC 직렬화의 서로 다른 경계를 두 시간대에서 재현하고, 날짜 전용 필드와 실제 시각을 안전하게 수정하는 기준을 제시한다.

하루를 더하기 전에 값이 바뀐 경계를 찾는다

JavaScript 날짜 하루 전 오류는 입력값이 달력의 날짜인지 특정 시각인지 먼저 나눠 진단한다. 날짜만 필요하면 YYYY-MM-DD를 보존하고, 시각이면 UTC 저장과 표시 시간대를 분리한다.

  • 원본 입력 문자열과 변환 직후·요청 본문·응답 값을 같은 테스트에서 기록한다.
  • 생일·마감일 같은 날짜인지, 시작 시간이 있는 예약 같은 시각인지 구분한다.
  • 날짜 전용 경로에서는 불필요한 Date·toISOString 변환을 제거하고 문자열을 왕복한다.
  • 서울과 로스앤젤레스 조건에서 저장 후 다시 연 날짜와 기존 시각 표시를 함께 확인한다.

대상은 날짜 선택값을 API로 저장하는 웹 개발자다. 입력 날짜 자체가 틀렸거나 접근 권한 때문에 저장이 거절되는 문제는 별도다. 운영 데이터를 먼저 고치지 말고 개인정보가 없는 테스트 값 하나로 확인한다.

입력 문자열, Date 생성, UTC 직렬화, 화면 표시를 따로 기록하면 저장된 순간이 달라진 문제와 같은 순간을 다른 날짜로 보여 준 문제를 구분할 수 있다.

예를 들어 생일 10월 26일은 사용자가 어느 나라에 있든 26일이다. 반면 서울에서 26일 00시에 시작한 작업은 로스앤젤레스에서 25일에 발생한 같은 순간일 수 있다. 화면에 25일이 보인다는 사실만으로 두 경우를 똑같이 보정하면 안 된다.

Date는 달력 한 칸이 아니라 한 순간을 담는다

Date는 기준 시점부터 흐른 밀리초로 한 순간을 표현한다. 현지 날짜를 읽는 getDate와 UTC 기준 날짜를 읽는 getUTCDate는 같은 값에서도 다른 날짜를 돌려줄 수 있다. 기기 시간대를 바꾼다고 저장된 타임스탬프 자체가 이동하는 것은 아니다.

현행 ECMAScript의 Date.parse 규칙에서 시간대 표시가 없는 YYYY-MM-DD는 UTC로 해석한다. 그런데 시각을 붙인 YYYY-MM-DDT00:00:00은 현지 시각으로 해석한다. 날짜 문자열 뒤에 자정만 덧붙이는 수정도 입력의 의미를 바꾼다.

같은 26일처럼 보여도 생성된 순간이 다르다
입력해석 기준점검할 경계
2026-10-26UTC 자정해외 현지 날짜로 표시
2026-10-26T00:00:00실행 환경의 자정서버와 브라우저 시간대
2026-10-26T00:00:00+09:00명시한 +09:00 시각UTC 직렬화 후 날짜 자르기

toISOString은 언제나 UTC 문자열을 반환한다. 서울 자정은 UTC로 전날 15시다. 변환 뒤 앞의 열 글자만 잘라 날짜로 쓰면 원래 고른 서울 날짜를 보존하는 코드가 아니다. 반대로 UTC 날짜 전용 문자열을 서쪽 지역의 현지 날짜로 읽으면 전날이 보일 수 있다.

다음은 파일·네트워크·DB를 바꾸지 않고 메모리에서 출력만 비교하는 예제다. date-check.cjs로 저장해 Node가 있는 macOS 또는 Linux 터미널에서 실행한다. 명령의 TZ는 이 프로세스에만 적용되며 시스템 시간대 설정을 바꾸지 않는다.

const raw = '2026-10-26';
const parsed = new Date(raw);
const midnight = new Date(2026, 9, 26);
console.log('TZ', process.env.TZ);
console.log('parsed ISO', parsed.toISOString());
console.log('local day', parsed.getDate());
console.log('midnight ISO', midnight.toISOString());
console.log('slice', midnight.toISOString().slice(0, 10));
console.log('round trip',
  JSON.parse(JSON.stringify({ date: raw })).date);
// Date의 숫자 인자에서 월 9는 10월이다.
TZ=Asia/Seoul node date-check.cjs
TZ=America/Los_Angeles node date-check.cjs
