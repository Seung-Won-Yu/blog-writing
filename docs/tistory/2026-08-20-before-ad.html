Windows 11 25H2에서 WMIC가 빠지며 PowerShell 전환이 필요해졌다

Windows 11 25H2에서 WMIC 유틸리티가 제거되며, 기존 관리 스크립트는 PowerShell Get-CimInstance로 이전해야 한다.

명령은 사라져도 WMI 데이터는 남는다

Microsoft의 Windows 11 25H2 문서는 기능 업데이트를 설치할 때 WMIC 유틸리티가 제거된다고 적고 있다. 선택 기능이나 DISM으로 다시 설치할 수는 있지만, 향후 완전히 제거될 예정이므로 재설치를 권하지 않는다. 당장 스크립트를 살리려고 다시 기능을 켜는 것은 응급 조치일 뿐, 이전을 대신하지 못한다.

여기서 구분할 것이 있다. WMIC는 WMI 정보를 명령 프롬프트에서 조회하는 옛 명령줄 도구다. 제거 범위는 WMIC 실행 파일이며, 윈도우의 시스템 관리 정보를 노출하는 WMI 자체는 영향을 받지 않는다. PowerShell의 CIM cmdlet은 같은 Win32_OperatingSystem, Win32_Process 같은 클래스를 조회하되, 결과를 가공할 수 있는 객체로 돌려준다.

먼저 어디서 WMIC를 쓰는지 찾는다

새 명령으로 옮기 전에 범위를 정해야 한다. 저장소의 .bat, .cmd, .ps1 파일뿐 아니라 예약 작업, 로그온 스크립트, 배포 스크립트, 설치 패키지의 사용자 지정 작업에도 WMIC가 숨어 있을 수 있다. 특히 WMIC 결과를 for /f로 나누거나 findstr로 걸러 다음 명령에 넘긴다면, 명령 한 줄만 바꾸어서는 호환성을 유지하기 어렵다.

# 현재 폴더의 스크립트에서 WMIC 사용처 찾기
Get-ChildItem -Recurse -File -Include *.bat,*.cmd,*.ps1 |
  Select-String -Pattern '\bwmic(?:\.exe)?\b' |
  Select-Object Path, LineNumber, Line

검색 결과를 클래스, 필요한 속성, 필터, 로컬·원격 여부, 출력의 다음 사용처로 나누면 교체 순서가 보인다. 하나의 배치 파일에서 WMIC를 세 번 부르더라도 같은 클래스의 결과를 재사용할 수 있다면 PowerShell에서는 한 번 읽어 변수에 담는 편이 더 낫다.

자주 쓰는 조회 6개를 Get-CimInstance로 옮긴다

대부분의 조회는 WMIC 별칭이 가리키던 WMI 클래스를 확인한 뒤 Get-CimInstance로 읽으면 된다. 결과 표시에 필요한 속성만 Select-Object로 고르면 로그와 파이프라인에서 쓰기 쉽다. 아래 예제는 Windows PowerShell 또는 Windows의 PowerShell 7에서 실행할 수 있으며, Get-CimInstance는 Windows 플랫폼에서만 제공된다.

# 1) 운영체제 버전과 빌드
Get-CimInstance Win32_OperatingSystem |
  Select-Object Caption, Version, BuildNumber

# 2) CPU 이름과 코어
Get-CimInstance Win32_Processor |
  Select-Object Name, NumberOfCores, NumberOfLogicalProcessors

# 3) BIOS 일련번호
Get-CimInstance Win32_BIOS |
  Select-Object SerialNumber

# 4) 고정 디스크 용량과 남은 공간
Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" |
  Select-Object DeviceID, Size, FreeSpace

# 5) 특정 프로세스
Get-CimInstance Win32_Process -Filter "Name='notepad.exe'" |
  Select-Object ProcessId, Name

# 6) 원격 PC의 운영체제 정보
Get-CimInstance Win32_OperatingSystem -ComputerName PC01 |
  Select-Object Caption, Version, BuildNumber
WMIC의 조회 대상은 유지하되, 출력을 속성으로 고르는 방식으로 바꾼다.
