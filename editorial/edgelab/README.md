# 모의투자부터 시작한 주식 앱 제작기

`edgelab`의 실제 구현과 모의투자 결과를 매주 한 편씩 공개하는 프로젝트 연재다.
수익률 자랑이나 종목 추천보다 **어떤 판단을 왜 내렸고, 무엇을 확인한 뒤 규칙을
바꿨는지**를 남긴다. 각 글은 직전 편에서 남긴 질문으로 시작하고 다음 편의 한
가지 질문만 예고한다.

1편은 2026-08-25에 이미 공개했다. 2편부터는 2026-08-29를 시작으로 매주
토요일 18:00 발행을 기준으로 한다.

## 편집 원칙

- 토요일 `실전 IT 아티클 > 프로젝트·회고`에 주 1회 발행한다.
- 금요일 `자동화·실험` 글과 별도 초안·회차·HTML로 관리한다.
- 제목 앞부분에는 독자가 찾을 문제를, 뒤에는 프로젝트 맥락을 둔다.
- 실제 코드·테스트·모의체결에서 확인한 범위만 쓴다.
- 수익률보다 비용, 실패, 차단 이유, 표본 수를 먼저 공개한다.
- 파라미터가 바뀌면 기준 커밋과 변경 이유를 함께 남긴다.
- 모든 글에 `실주문 경로 없음`, `투자 권유 아님`을 명시한다.
- 앞뒤 글 링크와 `모의투자부터 시작한 주식 앱 제작기 N` 표기를 유지한다.

## 연재 지도

기존 12주 압축안은 사용하지 않는다. 개발 순서와 발행 순서를 분리하고,
`아이디어 → 기획 → 후보 선정 → 모의체결 → 실패한 실험 → 검증 → 서버·앱 →
실제 운영 결과`로 이어지는 40편 본편을 기준으로 한다.

- [40편 연재 설계·회차별 증거·다음 편 질문](SERIES_PLAN.md)
- 뒤 회차를 먼저 완성했더라도 이야기 순서를 건너뛰어 발행하지 않는다.
- 실제 표본이 필요한 후반 회차는 결론을 미리 쓰지 않는다.
- 품질 문턱을 못 넘긴 회차는 `NO_PUBLISH_QUALITY`로 보류한다.
