## 2. 기존 자동 검사에 누락이 있었다

기존 탐지기는 `자동 생성 데일리 다이제스트` 같은 두 문구만 찾았다. 실제 공개된
다른 제목의 혼합 뉴스 글은 길이·소제목·출처가 충분해 검토 0건으로 분류됐다.

수정한 탐지기는 본문 **소제목**에서 `오늘의 뉴스 2개 이상`과 시험/별도 용어 절이
함께 나오는 경우를 `mixed_news_quiz`로 검토 분류한다. 단순 뉴스 묶음이나 문단에
옛 형식 명칭을 인용한 글만으로는 이 신호를 만들지 않는다. 신호의 가중치는 검토
수준이며 삭제·비공개·정책 위반을 결정하지 않는다.

- 수정 전: high 0 / review 0 / low 131 / error 0.
- 수정 후: high 0 / **review 8** / low 123 / error 0.
- 회귀 검증: `tests.test_audit_tistory_content` 11개 통과.
- 전체 검증: `python3 -m unittest discover -s tests` **561개 통과**.
- 현재 구조 검사: `tistory-content-audit-2026-10-27.json`, 같은 날짜 Markdown.

이 탐지기로 모든 요약·복제를 찾았다는 뜻은 아니다. 나머지 123편도 편집 품질을
보증하지 않는다. 최소 글자 수·글 개수·내부 8.5점은 AdSense의 승인 기준으로 쓰지 않는다.

## 3. 모바일 첫 화면과 광고 설정

최신 /251을 비로그인 상태의 실제 390×844 화면에서 확인했을 때 제목 다음에
Google 광고와 AdFit 상단 광고가 이어졌고 첫 본문 위치가 화면 위에서 약 853px였다.
즉 해당 관찰에서는 첫 화면을 지나야 첫 문장이 보였다. 광고 소재·채움 여부·로그인에
따라 높이가 달라지므로 모든 방문의 고정 수치로 일반화하지 않는다. 이후 로그인한
운영자 화면은 광고 표시가 달라져 비로그인 화면의 증거로 대체하지 않았다.

티스토리 관리 화면의 현재 설정:

- AdSense: 전체 자동·본문 상/중/하단·사이드바·목록 모두 사용 안 함.
- AdFit: 본문 상/중/하단·사이드바·목록 상/하단 모두 켜짐.
- 공개 Google 광고의 게시자 식별값은 이번 AdSense 신청 계정과 달랐다. 광고가
  보인다는 사실만으로 신청 계정의 승인을 추정하지 않는다. 그 광고의 소유·정책을
  임의로 변경하거나 CSS로 숨기지 않는다.
- 사용자는 본문 상단 AdFit만 끄는 제안에도 **유지**를 선택했다. 설정 변경 없음.

광고 개수만으로 위반이라고 판정하지 않는다. 현재 통지된 거절 사유도 광고 배치가
아니라 콘텐츠 가치다. 읽기 경험의 개선 여지는 남지만 이번에는 콘텐츠 개선에
집중한다. 공식 근거: [콘텐츠보다 많은 광고](https://support.google.com/publisherpolicies/answer/11169917?hl=ko),
[광고의 콘텐츠 방해](https://support.google.com/publisherpolicies/answer/11035030?hl=en).
