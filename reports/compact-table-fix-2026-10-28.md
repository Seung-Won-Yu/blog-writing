# 252번 2열 표 레이아웃 보완

사용자가 지적한 공개 화면을 재현했다. 바깥 table은 700px인데 안쪽 행과 caption은
421px였다. 내보내기는 `digest-compact-table`을 만들지만 스킨에는 해당 규칙이 없어
일반 표의 `display: block`이 적용된 것이 원인이다. 붙여넣기 오류가 아니다.

## 변경

- 생성 글의 `.daily-digest-post .digest-compact-table`에만 표 레이아웃을 추가했다.
- PC에서 전체 본문 폭을 채우고 제목을 왼쪽 정렬한다. 2열은 고정 열 배치와 한글
  단어 단위 줄바꿈, 긴 문자열의 비상 줄바꿈을 사용한다.
- 일반 글·3열 표의 CSS 규칙은 변경하지 않았다. 3열 이상은 기존 최소 560px와
  래퍼 내부 스크롤을 유지한다. 본문·이미지·광고 설정은 변경하지 않았다.
- `skin-layer.css`와 정식 `style.css`, 미리보기 CSS·도우미 해시를 함께 갱신했다.
- 실제 내보내기가 선택한 클래스에 대응하는 CSS가 있는지 검사하는 회귀 테스트를
  추가했다. 수정 전 2건 실패를 재현했고 수정 후 통과했다.
- BROWSER_QA 계약에 표 바깥뿐 아니라 caption·thead·tbody·행 너비 대조를 추가했다.

## 티스토리 실제 반영

앱 내 스킨 CSS 편집기에서 전체 선택·복사로 기존 CSS를 보존했다. 원격 CSS에는
로컬 정식 파일과 다른 내용이 있어 전체 덮어쓰기를 하지 않았다. 기존 원문 130,021자에
검수한 1,375자 패치만 추가했으며, 저장 전 `수정본 == 기존 원문 + 패치`를 확인했다.
원문 백업은 `/tmp/blog-writing-qa/2026-10-28/live-skin-before-compact-fix.css`다.
스킨 적용 후 새로운 공개 페이지 로드로 실제 결과를 검수했다.

| 실제 공개 /252 | 표/머리글/본문 너비 | 제목 | 결과 |
|---|---|---|---|
| PC 1280px · 2열 | 700 / 700 / 700px | 왼쪽 | 본문 폭 채움 |
| 모바일 390px · 2열 | 350 / 350 / 350px | 왼쪽 | 가로 넘침 없이 줄바꿈 |
| PC 1280px · 3열 | 700 / 700 / 700px | 왼쪽 | 기존 배치 유지 |
| 모바일 390px · 3열 | 560 / 560 / 560px | 왼쪽 | 350px 래퍼 안 스크롤 |

모바일 문서 너비는 뷰포트와 같은 390px다. 로컬 미리보기도 PC 700px / 모바일 335px
본문에서 같은 내부 너비를 확인했다. 실제 스킨과 로컬의 본문 여백 차이는 유지했다.
