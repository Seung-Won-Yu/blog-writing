1. arr[row][col]에서 바깥 반복문을 결정한다

패턴 먼저 움직이는 축 핵심 좌표
가로 채우기 행 고정, 열 증가 arr[row][col]
세로 채우기 열 고정, 행 증가 arr[row][col]
회전 출력 좌표 기준 입력의 열·행 교환

배열 저장 순서와 화면 출력 순서는 다를 수 있다. 채우기 코드는 패턴을 만들고, 출력 코드는 항상 행을 위에서 아래로 읽는다고 나눠 생각하면 덜 헷갈린다.

2. 숫자를 열 방향으로 채우기

static int[][] fillByColumn(int n) {
    if (n < 1 || n > 20) {
        throw new IllegalArgumentException("연습 크기는 1~20입니다.");
    }
    int[][] board = new int[n][n];
    int value = 1;

    for (int col = 0; col < n; col++) {
        for (int row = 0; row < n; row++) {
            board[row][col] = value++;
        }
    }
    return board;
}

열 하나를 고정하고 위에서 아래로 채운 다음 옆 열로 이동한다. fillByColumn(3)의 예상 결과는 아래와 같다. 크기를 20 이하로 제한한 것은 Java의 제한이 아니라 출력량을 줄이기 위한 이 글의 연습 조건이다.

1 4 7
2 5 8
3 6 9

3. 짝수 행은 오른쪽, 홀수 행은 왼쪽

static int[][] fillSnake(int n) {
    if (n < 1 || n > 20) {
        throw new IllegalArgumentException("연습 크기는 1~20입니다.");
    }
    int[][] board = new int[n][n];
    int value = 1;

    for (int row = 0; row < n; row++) {
        if (row % 2 == 0) {
            for (int col = 0; col < n; col++) {
                board[row][col] = value++;
            }
        } else {
            for (int col = n - 1; col >= 0; col--) {
                board[row][col] = value++;
            }
        }
    }
    return board;
}

여기서 짝수 행은 화면의 둘째 줄이 아니라 인덱스가 0, 2, 4인 행이다. 첫째 줄은 왼쪽부터, 둘째 줄은 오른쪽부터 채운다. 숫자는 계속 커지지만 출력할 때에는 각 행을 왼쪽부터 읽는다. fillSnake(3)의 예상 결과를 보면 둘째 줄만 감소하는 이유가 보인다.

1 2 3
6 5 4
7 8 9

4. 왼쪽으로 90도 회전하기

static int[][] rotateLeft(int[][] source) {
    if (source == null || source.length == 0
            || source[0] == null || source[0].length == 0) {
        throw new IllegalArgumentException("빈 배열은 회전하지 않습니다.");
    }
    int rows = source.length;
    int cols = source[0].length;
    for (int[] line : source) {
        if (line == null || line.length != cols) {
            throw new IllegalArgumentException("직사각형 배열이 필요합니다.");
        }
    }
    int[][] rotated = new int[cols][rows];

    for (int row = 0; row < rows; row++) {
        for (int col = 0; col < cols; col++) {
            rotated[cols - 1 - col][row] = source[row][col];
        }
    }
    return rotated;
}

이 메서드는 비어 있지 않고 각 행의 길이가 같은 직사각형 배열을 받는다. Java의 2차원 배열은 행마다 길이가 다를 수도 있으므로 먼저 검사한다. 새 배열을 만들어 반환하기 때문에 원본 값은 바꾸지 않는다.

다음 2행 3열 배열을 종이에 적고 왼쪽으로 돌려 보자. 오른쪽 위의 3은 왼쪽 위로, 왼쪽 위의 1은 왼쪽 아래로 간다. 결과 크기는 3행 2열이다.

회전 전       왼쪽 90도 회전 후
1 2 3         3 6
4 5 6         2 5
              1 4

숫자 3의 원래 좌표는 [0][2]다. 이를 [cols - 1 - col][row]에 넣으면 [3 - 1 - 2][0] = [0][0]이 된다. 모든 좌표를 외우기 전에 모서리 하나부터 대입해 보자.

실행해서 예상 결과와 비교하기

GridExamples.java 파일을 만든다. 아래 클래스 안의 표시한 위치에 위 세 메서드 fillByColumn, fillSnake, rotateLeft를 넣는다. 메서드는 main 안이 아니라 같은 클래스 안에 나란히 둔다. JDK가 필요하며 외부 라이브러리는 쓰지 않는다.

public class GridExamples {
    // 위의 세 메서드를 이 위치에 넣으세요.

    static void print(int[][] board) {
        for (int[] row : board) {
            System.out.println(java.util.Arrays.toString(row));
        }
    }

    public static void main(String[] args) {
        System.out.println("[세로]");
        print(fillByColumn(3));
        System.out.println("[지그재그]");
        print(fillSnake(3));
        System.out.println("[왼쪽 회전]");
        print(rotateLeft(new int[][] {{1, 2, 3}, {4, 5, 6}}));
    }
}

다음에는 크기 1로 바꿔 보자. 두 채우기는 [[1]], 한 칸 배열의 회전은 같은 값이 예상된다. fillSnake(0)이나 rotateLeft(new int[][] {{1, 2}, {3}})는 입력 오류를 알리는 예외가 예상된다. 예외를 잡지 않았으므로 잘못된 입력은 한 번에 하나씩 시험한다.

기본 개념의 근거는 Oracle Java 배열 튜토리얼이다. JDK 8 기준 문서이며, 여기서는 0부터 시작하는 인덱스와 행별 길이가 다를 수 있다는 배열 구조를 참고했다.

5. 실수하기 쉬운 부분

모든 반복 조건에 arr.length를 쓴다

직사각형 배열의 열 길이는 arr[row].length다. 행과 열 크기를 따로 저장한다.

채우기와 출력을 한 반복문에서 해결한다

패턴이 복잡해지면 저장을 끝낸 뒤 별도 메서드로 출력하는 편이 좌표를 검증하기 쉽다.

회전 방향을 눈으로만 판단한다

왼쪽 위, 오른쪽 위 같은 모서리 하나가 어디로 이동해야 하는지 좌표를 대입해 확인한다.

핵심 요약
  • 행과 열 중 어느 축을 먼저 움직일지 정한다.
  • 지그재그는 숫자보다 열 진행 방향만 바꾼다.
  • 왼쪽 회전 좌표는 [cols-1-col][row]다.
  • 직사각형 배열에서는 행·열 길이를 구분한다.
