# 2026-11-12 Google Meet 회의록 저장 위치 보완

[티스토리 144번](https://won0322.tistory.com/144)의 공개 본문과 원고 `2026-07-24`를 대조했다. 이전 보완본의 계정·회차·메일·Drive 확인 순서는 공개 글에 반영돼 있었다. 이번에는 회의 중 Gemini로 본 요약을 회의 후 Drive에서 찾는 상황을 보완했다.

- 10월 28일 저장한 Search Console 관측의 유효 검색어 49개를 작업 목록으로 확인했다. ‘구글 미트 회의록 저장 위치’는 9/28~10/25에 0클릭·4노출이었다. 사이트 검색어 표의 작은 표본이다. 144번의 페이지 실적과 연결하지 않았다. 앱 내 브라우저가 제공되지 않아 최신 Search Console과 색인 상태는 확인하지 못했다.
- ‘자료별로 찾을 곳’에 자동 회의록, Meet의 Gemini 개인 답변, 직접 작성한 회의록의 확인 경로를 구분했다. 자동 회의록은 해당 회차의 Calendar 첨부·안내 메일·주최자 Drive에서 찾는다. Gemini에게 물어보기만 한 경우 공유 문서는 생기지 않는다. Docs에서 일정 정보를 불러온 수동 문서는 작성자에게 링크를 확인한다. 실제 계정에서 회의를 열거나 공유 설정을 바꾸지 않았다. [Meet 자동 회의록](https://support.google.com/meet/answer/14754931?hl=ko), [Gemini에게 물어보기](https://support.google.com/meet/answer/16024610?hl=ko), [Calendar 일정에 회의록 추가하기](https://support.google.com/docs/answer/11324079?hl=ko)
